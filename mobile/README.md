# Money Tracker V2 Mobile

Expo/React Native starter untuk Money Tracker native app.

## Run locally

```bash
cd mobile
npm install
npm start
```

Lalu buka app **Expo Go** di iPhone/Android dan scan QR code dari terminal.

## Current scope

- Dashboard native mobile.
- Fetch saldo akun dari Google Sheets Apps Script.
- Fetch transaksi terbaru dari Google Sheets Apps Script.
- Struktur awal untuk lanjut ke input transaksi native dan sync queue.
